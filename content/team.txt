# ──────────────────────────────────────────────────────────────────────
#  DELPHIQUE WEBSITE · TEAM LINKEDIN PROFILES
#
#  Each line links a team member's photo to their LinkedIn profile:
#
#     linkedin = Name | https://www.linkedin.com/in/...
#
#  • The name must match the name in their photo's file name in content/photos/team
#    (capitals, extra spaces and dots don't matter).
#  • A link copied from the LinkedIn app (with ?utm_source=… on the end) is fine.
#  • A line for someone without a photo yet is fine too: /check lists it, and it starts
#    working as soon as their photo is uploaded.
#  • The same link shows next to a name in the footer's Contact list.
#  • The | key is Shift + \ on the keyboard.
#
